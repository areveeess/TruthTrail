DATABASE_URL stays optional in Settings, and the lifespan does not require it, until plan 03-12 adds the startup check `require_database_unless_demo` (a lifespan-time check, not a Settings validator, so the strict `get_settings()` that the /v1 rate-limit callable reads on every request never fails for a missing database; an app built with an injected engine is exempt from that check).
