  <files>src/truthtrail/core/readiness.py, tests/test_readiness_registry.py</files>
  <behavior>
    - Registering a check stores it under its name; `run()` returns `{name: True}` for a check that returns True, in registration order.
    - A check that returns False, None or any value other than True is reported as False (fail closed).
    - A check that raises any Exception is reported as False; the log record carries the check name and the exception CLASS name only, never `str(exc)`; the exception does not propagate.
    - BaseException subclasses that are not Exception (KeyboardInterrupt, SystemExit) are not swallowed.
    - `register` with a blank or whitespace-only name raises ValueError; registering the same name twice raises ValueError and keeps the first check.
    - `run()` on an empty registry returns `{}`.
  </behavior>
