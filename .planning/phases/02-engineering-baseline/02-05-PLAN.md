## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser origin -> API | Which origins may read responses is decided by configuration |
| unhandled exception -> client | Exception text must never reach a response body or log |
| environment -> construction-time settings | Misconfiguration must fail loudly without echoing values |
