<interfaces>
Fixed signatures (Phase 3 imports these; D-03 rates them costly to change):
- `truthtrail.core.cascade.CascadeEvent`: frozen dataclass with `event_id: str`, `parent_event_id: str | None`, `observed_at: datetime` (timezone-aware).
- `CascadeError(ValueError)`.
- `order_events(events: Iterable[CascadeEvent]) -> list[CascadeEvent]`: new list, input untouched, sort key `(observed_at, depth, event_id)` where depth is the number of known ancestors reachable through `parent_event_id` (a missing parent ends the chain); so on equal timestamps a parent precedes its child.
- `validate_cascade(events: Iterable[CascadeEvent]) -> None`: raises CascadeError for duplicate event ids, a naive `observed_at`, a self-parent or any parent cycle, and a present parent whose `observed_at` is later than its child's (equal timestamps are valid).
- Adapter `cascade_events_from(events: Iterable[HasTimestamp]) -> list[CascadeEvent]` (input order preserved) where `HasTimestamp` is a structural Protocol with read-only `event_id`, `parent_event_id` and `timestamp: str`; `schemas.Event` satisfies it. It parses ISO-8601 (the fixture uses the `...Z` form), normalises offsets to UTC, and raises CascadeError for an unparseable or naive timestamp. `schemas.Event` has `timestamp`, not `observed_at`; the adapter is where that naming gap is bridged.
Committed fixture facts: each of its three cascades lists the news root, then the three platform chains one after another; none is sorted by timestamp and one has timestamp ties. `load_demo_fixture()` (api/analyze.py) is lru_cached, validates the synthetic label, and is a string patch target (`truthtrail.api.analyze.load_demo_fixture`, `FIXTURE_PATH`). The strict xfail tests in tests/test_char_simulator.py pin the legacy child-before-parent defect and must keep failing for the same reason.
</interfaces>
