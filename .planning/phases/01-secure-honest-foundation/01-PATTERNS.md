## Shared Patterns

### Conventions to follow in all new Python (CONVENTIONS.md / CLAUDE.md)
4-space indent, double quotes, `snake_case`, annotate new signatures, `logging.getLogger(__name__)` (never `print`), triple-double-quoted docstrings. The only in-repo docstring example is `risk_analyzer.py:2-5` (triple-double-quoted, with an emoji-comment style that new code must NOT copy). Flat bare-name imports, run from the repo root.

### Secret hygiene (all files)
Source: RESEARCH Pattern 2 and D-16. The key travels only in the `X-Api-Key` header. No `str(exc)`, URL, query or key in any response body, log record or exception text. Every upstream exception is raised `from None`. Tests assert absence of `FAKE_TEST_KEY`.

### Error shape (all handlers)
Source: RESEARCH "Problem handlers (executed)". One `problem_body()` builder and `application/problem+json` for upstream, validation, 404/405 and 500, each carrying `synthetic`, `source_status` and `data_as_of: null` (D-15).

### Provenance on success
Source: RESEARCH Pattern 4. `meta` = `{synthetic, data_as_of, source_status}` on every 2xx. Live: `synthetic` false and `data_as_of` is the receive time in UTC with microseconds stripped. Demo: values come from the fixture, never "now".
