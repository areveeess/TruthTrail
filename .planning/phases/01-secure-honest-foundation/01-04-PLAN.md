<objective>
Make every failure honest and uniform: the GNews adapter classifies each upstream outcome into a typed error, and one problem+json builder renders upstream errors, validation errors, 404/405, configuration errors and unexpected exceptions with the same RFC 9457 shape plus provenance members. Input is validated before any upstream call.

Purpose: FND-02 (502/503 with a machine-readable body, never a fabricated 200; ROADMAP success criterion 2) and the 422 half of FND-04. The response success shape is not changed here (plan 01-05 owns the envelope).
Output: `problems.py`, rewritten error handling in `gnews_fetcher.py`, `main.py` validation and wiring, two new test modules, flipped legacy xfail markers.
</objective>
